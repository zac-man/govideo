# Frame Foundry 文生图工作台

一个本地网页工作台，自动读取 `素材/01_GPT-Image-2_图片素材库` 下的场景、角色和道具。选中资产后可查看其整体连续性、图片准备任务和完整提示词，并调用 `gpt-image-2` 生成图片。

## 启动

在仓库根目录执行：

```bash
node image-studio/server.mjs
```

浏览器打开 [http://127.0.0.1:3016](http://127.0.0.1:3016)。

## 图片归档规则

每次生成都会保存到所选资产目录：

```text
素材/01_GPT-Image-2_图片素材库/<类别>/<资产>/03_生成记录/YYYY-MM-DD/
```

同目录还会保存 `参数记录.json`，包括完整提示词和本次 API 请求参数。生成完成后请按现有工作流，将通过连续性检查的图片手动移动到 `04_已确认图片`。

API Key 配置在 `image-studio/server.mjs`，不会进入网页或生成记录。

## 本地任务记录

`image-studio/data/generation-tasks.json` 保存任务号、关联资产、轮询状态和已归档的图片路径。刷新页面时，选择资产会自动恢复该资产最近一次生成结果；服务重启时，未完成任务会继续轮询。
