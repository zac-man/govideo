# 02.3｜道具与连续性关键帧

## 道具和状态素材

| 编号 | 道具 | 特别要求 |
|---|---|---|
| P01 | 金色王冠 | 厚重金冠、百合尖饰、正面椭圆红宝石、两侧绿宝石；国王手持、落地、奥萝拉拾起、戴上都是**同一顶**。 |
| P02 | 王子佩剑 | 银色十字护手、深蓝缠柄、圆形银剑首、黑鞘银边；拔剑前挂在王子**左腰**，后由公主右手拔出。 |
| P03 | 纺车与纺锤 | 木制中世纪手摇纺车与普通细金属纺锤；第 06 镜纺车燃烧，第 07～08 镜纺锤作为“诅咒应验”的公众传说画面。纺锤不能发光或释放魔法。 |
| P04 | 婴儿摇篮与襁褓 | 金色王室纹章，与 C01a 一致。 |
| P05 | 大主教圣书 | 深棕皮革封面、金属十字扣；可翻开与合上。 |
| P06 | 密信、契约、王国地图 | 蜡封用公主的银枝叶徽记；用于后段闪回，文字不要交给生成模型写，若需可后期合成。 |
| P07 | 高塔/荆棘铁门锁与钥匙 | 青铜老式门锁，锁孔、钥匙形状固定；只在反转后揭露高塔与荆棘通路是人为控制，开场不展示锁。 |
| P08 | 婚礼头纱 | 与 C01c/C01d 的同一条半透明头纱；最后盖住王子面容。 |
| P09 | 酒杯、碎杯 | 宾客反应镜头备用。 |
| P10 | 王室旗帜和玫瑰 | 暖场景反复出现；政变后旗帜不必突然更换。 |

另做 5 张**连续性关键帧**：K01 王子跪地、公主整理披风、剑仍在左腰；K02 公主握住剑柄；K03 王子倒在红毯偏左、公主婚纱有固定血迹、王冠落在右前方石地；K04 卫兵剑指国王、仙女在两侧侧廊、大主教跪在公主面前；K05 国王已被带走，公主在王子身边摘头纱，王子仍在 K03 位置。关键帧均基于同一 B05/B06 位置图制作。

道具图生成统一前缀：`9:16 高规格 3D 动画电影道具设定图，架空西欧中世纪晚期，真实金属/木材/织物质感，非真人实拍，物件完整清晰，中性背景，单件道具，无文字。` 后接表中该道具的形状、材质和用途。关键帧 K01～K05 则应使用相应教堂背景、角色图和道具图合成，不能在中性背景生成。
