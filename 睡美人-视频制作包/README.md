# 《睡美人：百年王冠》视频制作包

来源：[故事大纲](../故事大纲.md)与用户提供的人物设定。当前剪辑方案为 **9:16、高规格 3D 动画、45 镜、2 分 50 秒**；**3 分 20 秒只是时长上限**，以画面和故事节奏为准，不为凑时长加空镜。每镜先在豆包/Vidu 生成 5～10 秒，剪辑只取表中最有效的 3～5 秒。前两幕用 50 秒讲清熟悉的《睡美人》，婚礼用 8 秒铺垫，**第 17 镜在 00:58 拔剑**；从这里起停止旁白，用角色现场对白、闪回和动作推进揭谎、翻盘、登基。第 05 幕是 35 秒的父女交锋；第 06～07 幕把卫兵倒戈、公开继位、国王下跪及高塔落锁连续兑现。

前段只用诅咒、纺锤、沉睡、荆棘、王子之吻与婚礼让观众认出《睡美人》。公主从小被囚禁、仙女传信、国王与第十三位仙女串通等真相，只在拔剑后揭露。
