# GPT-Image-2 图片工作流

图片素材只在 `01_GPT-Image-2_图片素材库` 生成和筛选。每个资产按以下状态流转：

`00_资产定义.md` → `01_图片准备/图片清单.md` → `02_GPT-Image-2_提示词/文生图提示词.md` → `03_生成记录/` → `04_已确认图片/`

- 每次只生成一个明确的静态画面任务；先锁定浩宇，再锁定次卧、办公区、地铁和核心道具。
- 仅将通过连续性检查的图片放入 `04_已确认图片`；未采用结果放在 `05_淘汰图片`，保留原因。
- 图片文件名遵循：`资产编号_主体_视角或状态_v001.png`。
- 图片中禁止可读文字、品牌标识、代码、聊天界面和时间；这些内容全部由后期完成。
