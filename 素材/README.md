# 《今天也没发生什么》AI 素材工作区

## 工作流

1. 在 `01_GPT-Image-2_图片素材库` 使用 GPT-Image-2 文生图，生成并筛选角色、场景、道具的静态图片。
2. 将每个镜头实际选用的图片副本放入 `02_小云雀_视频镜头包/.../01_镜头素材/` 下对应的角色、场景、道具目录。
3. 只在 `02_小云雀_视频镜头包/.../02_小云雀_镜头提示词/` 编写和调用小云雀视频提示词；提示词不与图片素材混放。
4. 视频原片、精选镜头、后期合成和声音按镜头分别归档。

## 根目录

- `00_工作流规范`：全局连续性、文件命名、GPT-Image-2 与小云雀交接规则。
- `01_GPT-Image-2_图片素材库`：唯一的图片资产源；只有其中 `04_已确认图片` 可被镜头包引用。
- `02_小云雀_视频镜头包`：44 个可独立执行的视频镜头包。
- `03_镜头候选池`：跨镜头可复用但尚未确认的备选素材。
- `04_剪辑交付物`：代理、合成、声音和成片。
