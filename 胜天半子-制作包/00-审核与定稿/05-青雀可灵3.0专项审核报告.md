# 青雀可灵 3.0 Omni 专项审核报告

审核日期：2026-07-26  
依据：[可灵视频 3.0 Omni 使用指南](https://docs.qingque.cn/d/home/eZQDPQ5RCKYKpTbz1poE88YSp?identityId=2Ha76zGX5gS)

## 审核结论

整套制作包已从“自拟 API 参考图请求”改成适配青雀文档的“角色主体＋普通参考图＋绑定音色＋自定义多镜头”工作流。外部视频任务由 8 条调整为 10 条，不是把画面拆碎，而是修复原先数条任务严重超出台词容量的问题；每条仍对应一个完整戏剧段落。

## 发现并修正的高影响问题

### 1. 台词超过 15 秒任务容量

旧 VID-006 在三个 5 秒镜头中同时承载饥荒、追问、幼猫饿死、囤粮与不回头等长句，模型很可能加速、吞字、改词或造成口型错位。现拆为：

- VID-007：饥荒、鼠疫与追问。
- VID-008：囤粮、挣扎与不回头。

定罪段也按同样原则拆开。D01–D24 均获得明确的说话时长、停顿、重音与闭口监听规则。

### 2. 把角色当普通参考图，浪费主体与音色能力

原方案反复上传角色设定拼版。现改为：

- 成年狸同伟：全身 A 图＋头肩 B 图，创建 `@狸同伟`，绑定沙哑中低音。
- 喵亮平：全身 A 图＋头肩 B 图，创建 `@喵亮平`，绑定低沉平静中低音。
- 年轻狸同伟：单图创建 `@年轻狸同伟`，本片无对白，不绑定音色。

这样可减少跨视频变脸、变声、花纹漂移与口型不稳。

### 3. 四视图拼版不利于多图主体

角色图已取消同一画布四视图。成年主角各用两张独立清洁源图：一张全身锁结构和服装，一张头肩锁脸部、花纹与口型。B 图要求以上一张 A 图作为输入参考，避免重新抽卡。

### 4. CS/LR4 提示词自相矛盾

旧提示词正向要求“低调瞄准镜”，负面词又禁止“瞄准镜”。现已改为“固定式瞄准镜必须保留”，只排除额外光学附件、装填、瞄准画面和操作教学。

### 5. 人物造型与孤鹰岭原剧不符

现在时继续硬锁原剧孤鹰岭的黑白关系：

- 狸同伟：纯黑长袖衬衫、深炭灰西裤，无外套、围巾、领带。
- 喵亮平：干净白色长袖衬衣、深色西裤，无外套、围巾、领带。

所有视频提示词均重复这组关键服装锁，避免模型自动补成警服、西装外套或户外大衣。

### 6. 产品指南被误写成 API 字段

旧 `03-Omni请求规范.md` 使用了没有从青雀页面得到确认的 JSON 字段。现已删除该做法，改成可灵界面操作规范。若以后要走 API，必须另取正式 API 文档，不把产品指南反推成接口定义。

## 视频提示词优化标准

每条完整提示词现统一包含：

1. 角色、服装、空间和风格硬锁。
2. 绑定音色、口型、闭口监听和无字幕规则。
3. `镜头编号｜秒数｜景别/运镜｜动作与台词`。
4. 句内停顿、重音、情绪强度和句尾状态。
5. 当前镜头必要的环境声。
6. 与下一条衔接所需的末帧状态。
7. 只针对本条高风险错误的负面约束。

## 资产控制结果

| 类别 | 数量 | 说明 |
|---|---:|---|
| 图片资产组 | 6 | 只保留重复出现、需要跨任务稳定的内容。 |
| 最终图片 | 8 | 5 张角色主体源图＋3 张普通参考图。 |

| 普通参考图 | 3 | 木屋外景、木屋内景、CS/LR4。 |

| 单任务输入 | 2–5 | 不超过无参考视频时的 7 个上限。 |
| 一次性元素 | 不建资产 | 由所属视频提示词直接生成。 |

## 实际生成时的审核优先级

1. 台词是否逐字正确、是否吞字或两人同时开口。
2. 绑定音色是否跨任务稳定，普通话人名是否读对。
3. 黑衬衫/白衬衣、猫科脸、花纹、耳缺、疤痕和五指手是否稳定。
4. 木屋上下空间与 CS/LR4 是否连续。
5. 闪回的一次性元素是否清楚服务剧情。
6. 终场是否只在屋外以声音和反应表达，标题是否准确。

若 1–3 不合格，应直接重生对应任务；不能用后期加速、改台词或补字幕掩盖。
