## 拟人化结构硬锁

- 所有猫人和犬人都必须双足直立，保持人类式肩、肘、腕、髋、膝结构。
- 双手均为覆毛五指手，每手恰好五指，可自然握持与伸展；不得生成肉色人手、爪子手套或圆形宠物爪。
- 头部必须是完整动物头脸，而不是人脸加猫耳，也不是动物头套。
- 每名角色只能有一条尾巴；服装必须为尾巴留出自然开口。
- 儿童使用儿童人体比例，但仍保持同一拟人猫人世界观。
- 场景、门窗、台阶、猎枪、家具和粮袋全部使用人类尺度。

## 使用规则

- Prompt 中出现角色、场景或道具时，必须使用本表 ID 前缀 `@`。
- `contents` 中 `refer_image.id` 必须与 Prompt 完全一致。
- 每个视频任务只传文件列出的引用图；不得为了“更稳”擅自超过 7 张。
- 参考图只是身份和外观依据，不是首帧，不要写入 `first_frame` 或 `last_frame`。
- 同一角色若漂移，先返工其角色参考图；不要增加重复 ID 或改名。
