# 场景：暴风雨前天空与湿地

- 资产策略：不单独出图；作为现在时每个视频 Prompt 内的天气与氛围描述。
- 尺度：约 1.8 米双足直立拟人角色所在的人类尺度环境；低机位为成年人膝部高度，不是宠物猫贴地视角。
- 核心：铅灰厚云压低山脊，冷月被云层围住；湿土上的枯叶全部伏下，草梗不动。
- 声音想象：极远闷雷只出现半声，随即被群山吞没；没有雨声、风声和机械声。
- 用途：为所有现在时镜头提供统一天气、色温和静止状态。
- 状态变化：只有 VID-007 的第二镜中风才突然出现，VID-008 结尾叶片重新伏下。
- 禁止：闪电劈地、龙卷风、巨大暴雨墙、彩色天空、星河、日出、直升机。
