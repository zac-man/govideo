# 文生图与可灵主体源图任务

本目录保留 **6 个资产组、8 张最终图片**：

- 成年狸同伟：2 张主体源图。
- 年轻狸同伟：1 张主体源图。
- 喵亮平：2 张主体源图。
- 木屋外景、木屋内景、CS/LR4：各 1 张普通参考图。

任务文件仍只有 6 组，不为闪回群演和一次性道具继续拆图。成年主角各多一张近景源图，是为了使用可灵 3.0 的“多图角色主体”，提高跨任务的脸部、花纹、服装与口型稳定性。

## 固定参数

- 模型：`GPT Image`
- 尺寸：`1024×1024`
- 画幅：`1:1`
- 格式：PNG
- 生成顺序：IMG-001-A → IMG-001-B → IMG-002 → IMG-003-A → IMG-003-B → IMG-007 → IMG-008 → IMG-015。
- B 图必须把同角色 A 图作为输入参考图生成，不允许从零抽卡。

## 可灵导入方式

| 图片 | 可灵用途 |
|---|---|
| `IMG-001-lihua-A/B.png` | 合并创建角色主体 `@狸同伟`，并绑定音色。 |
| `IMG-002-lihua-young.png` | 创建角色主体 `@年轻狸同伟`，不绑定音色。 |
| `IMG-003-liang-A/B.png` | 合并创建角色主体 `@喵亮平`，并绑定音色。 |
| `IMG-007-cabin-ext.png` | 普通参考图 `@木屋外景`。 |
| `IMG-008-cabin-int.png` | 普通参考图 `@木屋内景`。 |
| `IMG-015-cs-lr4.png` | 普通参考图 `@CSLR4`。 |

垃圾场、洪水、疗伤院、饥荒街、繁华街、儿童、犬族、社区居民、粮袋、草药、空食盆、罐头粮堆、54 式手枪与标题均不单独生成。

## 总体验收

- 角色源图只出现一个角色，不做四视图拼版、分屏、文字标签或比例线。
- 三名角色必须是完整猫科头脸、人类比例双足身体、覆毛五指手、固定服装和单条尾巴。
- A/B 图的花色、耳缺、疤痕、眼色和服装完全一致；B 图只改变景别，不重新设计角色。
- 木屋按约 1.8 米直立角色尺度制作；CS/LR4 按人类尺度制作。
- 任何基础身份错误都在图片阶段返工，不能带进可灵主体库。
