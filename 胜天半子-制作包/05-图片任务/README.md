# gpt-image-2 参考图任务

本目录共 20 个独立图片任务。每个文件的代码块都是已经拼装完成的最终提示词，可直接单独提交，不要再拼接全局词。

## 拟人化形象硬要求

- IMG-001～006 必须生成拟人猫人/犬人：完整动物头脸与毛发、人类比例直立身体、覆毛五指手、固定服装和单条尾巴。
- 不接受普通四足宠物猫、纯人脸加猫耳、动物头套、玩偶服或兽装真人感。
- IMG-007～014 的门窗、街道、洪水、台阶和机位全部按约 1.8 米直立角色设计。
- IMG-015～019 的道具全部为人类尺度，并适合覆毛五指手使用。
- 每个任务提示词已经独立写全上述相关约束，不需要另拼公共前缀。

## 固定参数

- 模型：`gpt-image-2`
- 尺寸：`1024×1024`
- 画幅：`1:1`
- 格式：PNG
- 每个任务：1 张图
- 文件命名：严格使用任务文件里给出的输出文件名

## 生成顺序

1. IMG-001–006：角色与群演。
2. IMG-007–014：现在时和闪回场景。
3. IMG-015–019：道具。
4. IMG-020：标题卡。

角色参考图通过后再生成场景与道具。任何角色的拟人结构、五指手、服装、花色、耳缺、疤痕、眼色、尾巴或围巾不合格，都应先重生角色图，不能把错误资产带入视频。
