## 通用提交规则

- 严格按任务顶部的顺序上传，引用为 `@图片1`、`@图片2`……；不要沿用旧的 `@名称` 别名。
- 复制完整提示词。复杂镜头按“总体定义 → 镜头顺序 → 约束”三段组织。
- 每镜仅一种运镜；一名角色说话时，其他角色闭口。
- 无字幕、无文字、无水印、无Logo；VID-010 的标题在后期添加。
- 无参考声音时，抽检跨片声线稳定；有声音参考时，把它放在关键人物图之后。
