# Kling 3.0 Omni 镜头任务

本目录共 15 个可独立提交的 Omni 参考图视频任务。每个任务文件已包含：

- 任务总时长与每个内部镜头秒数。
- 必须上传的参考图及准确引用 ID。
- 已拼装完成的完整 Omni Prompt。
- 1:1、1080p、原生音频、多镜头设置。
- 台词与验收标准。

## 总规则

- 只用 `refer_image`；禁止 `first_frame`、`last_frame` 和参考视频。
- Prompt 代码块必须整段原样提交，不能只复制“镜头”部分。
- `contents` 中参考图 ID 必须与 Prompt 的 `@id` 一致。
- 每个任务的镜头时长之和必须等于任务总时长。
- 台词由 Omni 原生音频生成，不做后期配音；不得让模型擅自改词。
- 除 VID-015 的标题卡外，所有镜头禁止字幕和可读文字。
- 所有动物角色均为双足直立拟人猫人/犬人：完整动物头脸、人类比例身体、覆毛五指手、固定服装和单条尾巴。
- 禁止普通四足宠物猫、纯人脸加猫耳、动物头套、玩偶服和兽装真人感。
