# Kling 3.0 Omni 镜头任务

本目录共 8 个可独立提交的 Omni 参考图视频任务。每个任务按完整叙事段落组织；一次性闪回、群演和细节道具都直接在镜头 Prompt 中生成，不再为它们单独出图。

## 总规则

- 只用 `refer_image`；禁止 `first_frame`、`last_frame` 和参考视频。
- Prompt 代码块必须整段原样提交，不能只复制“镜头”部分。
- `contents` 中参考图 ID 必须与 Prompt 的 `@id` 一致；一次性元素不需要 ID 或参考图。
- 每个任务的镜头时长之和必须等于任务总时长；台词由 Omni 原生音频生成。
- 所有动物角色均为双足直立拟人动物：完整动物头脸、人类比例身体、覆毛五指手、固定服装和单条尾巴。
- 仅终场最后两秒允许出现“胜天半子”标题；其余镜头禁止字幕和可读文字。
