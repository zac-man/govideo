# 可灵 3.0 Omni 视频任务

本目录共 **10 个可独立提交的叙事段落**。拆分依据不是“一个画面一个任务”，而是：

- 单条不超过可灵 3.0 的 15 秒上限；
- 原台词按自然普通话语速能够完整说完；
- 每条内部使用 3–5 个自定义镜头承载完整戏剧节拍；
- 一次性闪回、群演和细节道具继续在视频中直接生成。

旧版 8 条虽然更少，但 VID-003、VID-006 等任务在 5 秒内塞入过长台词，容易吞字、抢词和口型漂移。本版增加到 10 条，仍比早期 15 条更集中，同时不牺牲台词。

## 通用提交规则

- 角色从主体库选择；木屋和 CS/LR4 上传为普通参考图。
- 复制每个文件中的“完整 Omni 提示词”整段，不要只复制镜头句。
- 使用 1:1、1080p、对应时长、自定义多镜头、原生音画同步。
- 不输入参考视频，不使用首帧或尾帧图片。
- 所有台词逐字生成，不显示字幕；每镜只一位角色开口。
- `@狸同伟` 和 `@喵亮平` 使用已绑定音色；画外音也沿用 `@喵亮平` 的同一音色。
- 仅 VID-010 最后 3 秒允许出现标题“胜天半子”。
