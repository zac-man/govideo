# 生成与返工顺序

## 第一批：角色源图

按 A/B 依赖顺序生成 5 张角色源图：

1. `IMG-001-lihua-A.png`
2. 以上图为输入参考生成 `IMG-001-lihua-B.png`
3. 以成年 A 图为身份参考生成 `IMG-002-lihua-young.png`
4. `IMG-003-liang-A.png`
5. 以上图为输入参考生成 `IMG-003-liang-B.png`

验收黑衬衫狸同伟、白衬衣配酒红领带喵亮平的孤鹰岭对照，以及完整猫科头脸、双足结构、五指手、花色、耳缺、疤痕与尾巴。

## 第二批：可灵主体与音色

1. 用 IMG-001-A/B 创建 `@狸同伟`。
2. 用 IMG-002 创建 `@年轻狸同伟`。
3. 用 IMG-003-A/B 创建 `@喵亮平`。
4. 为两名成年主体分别绑定 8–15 秒干净、单人、中性普通话音频。
5. 用一条短测试视频确认两个人名读音、声纹、口型和闭口监听。

音色基准一旦通过，不要在每个任务中重新描述年龄、音高或口音，只写该句表演。

## 第三批：核心空间与道具

生成 IMG-007、IMG-008、IMG-015，确认木屋内外属于同一人类尺度空间，CS/LR4 的枪托、固定瞄准镜、颜色和磨损稳定。不要为闪回群演、粮袋、草药、空盆、罐头、54式手枪或标题另做图。

## 第四批：分段生成

- 对峙建立：VID-001–004。
- 英雄回忆：VID-005–006。
- 缺席指控：VID-007–008。
- 崩塌与终场：VID-009–010。

每条先验台词，再验画面。一次性画面不理想时，只重生所在 VID。

## 最小返工原则

| 问题 | 返工对象 |
|---|---|
| 角色脸、花色或服装跨任务漂移 | 先检查角色主体源图；源图正确时只重生出错 VID。 |
| 成年主角跨任务变声 | 检查主体绑定音色，不要在提示词中创建新声纹。 |
| 台词漏字、改词、抢话或口型错位 | 只重生对应 VID；不得删词或加速。 |
| 一次性闪回、群演或细节道具不理想 | 只重生对应 VID，不补做参考图。 |
| 木屋或 CS/LR4 漂移 | 检查对应普通参考图，再重生受影响 VID。 |
| 终场出现直接伤害或血腥 | 只重生 VID-010，强化“屋外固定机位、手枪不可见”。 |
