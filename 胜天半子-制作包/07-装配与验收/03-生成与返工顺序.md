# 生成与返工顺序

## 第一批：角色锁定

先生成并验收 IMG-001、IMG-002、IMG-003。重点比较：

- 成年与年轻狸同伟的额头纹、左耳缺口、琥珀眼和围巾是否属于同一角色。
- 成年狸同伟右眼下有浅疤，年轻版没有。
- 三名主角色是否都是完整猫科头脸、人类比例双足身体、覆毛五指手和单条尾巴。
- 狸同伟的长外套/年轻版短夹克、喵亮平的深蓝黑长外套是否稳定。
- 喵亮平面罩斑、绿色眼睛、胸白毛、白色五指手与足部是否稳定。

任何一项不通过，先重生角色图，不继续视频。

## 第二批：群演、场景与道具

1. 生成 IMG-004–006，锁定两名猫人儿童、三名犬人和五名社区猫人。
2. 生成 IMG-007–014，确认门窗、街道、洪水和台阶为约 1.8m 拟人角色尺度。
3. 生成 IMG-015–019，检查道具无字、无品牌且为人类尺度。
4. 生成 IMG-020，必须逐字检查“胜天半子”。

## 第三批：声音基准

先生成 VID-002。只有同时满足以下条件才继续：

- `狸同伟`准确读作 lí tóng wěi，不能读成“狸同步”。
- 喵亮平声线低沉平静；狸同伟声线疲惫沙哑；二者明显可区分。
- 台词完整、普通话自然、口型同步、无字幕。

后续任务沿用各文件中完全相同的声线描述。若声线明显漂移，只重生该视频任务；不要用后期配音覆盖。

## 第四批：按段落生成

- 现在时对峙：VID-001–004。
- 英雄闪回：VID-005–007。
- 饥荒与缺席：VID-008–010。
- 崩塌与终场：VID-011–015。

每一批通过后再进入下一批，避免错误资产扩散。

## 最小返工原则

| 问题 | 返工对象 |
|---|---|
| 角色退化成四足猫、纯人脸或头套感 | 先重生对应角色参考图，确保双足、动物头脸、五指手、服装和尾巴全部通过。 |
| 角色花色、耳缺、疤痕、服装、手指或尾巴错误 | 先检查角色参考图；参考图正确时只重生出错视频。 |
| 台词漏字、改词、重叠说话 | 只重生对应 VID 文件，不改台词文本。 |
| 镜头切分不清 | 简化该镜动作，不增加参考图。 |
| 场景色温漂移 | 只重生对应场景图或视频，不修改角色图。 |
| 标题错字 | 重生 IMG-020，再重生 VID-015。 |
| 终场出现直接伤害或血腥 | 只重生 VID-014，并加强“屋内不可见、只用画外声”约束。 |
| 参考图超过 7 张 | 按资产引用矩阵删除多余图，不改 ID。 |
