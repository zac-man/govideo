# 最终验收清单

## A. 剧情与台词

- [ ] `00-审核与定稿/02-台词对照表.md` 的 D01–D24 全部出现且逐字正确。
- [ ] 没有“我只问你一句”“你为什么没回来”“别再说了”“同伟，回来”等旧稿新增或改写台词。
- [ ] `狸同伟`没有被读成“狸同步”。

- [ ] 终场两句完整保留；直接动作、伤口、血液和身体结果不在画面中出现。

## B. 角色一致性

- [ ] 狸同伟全片都是棕灰狸花，不是橘猫；左耳缺口、琥珀眼、右眼下浅疤、深灰围巾固定。
- [ ] 年轻狸同伟同纹同眼同耳缺，但没有右眼下疤，体型略瘦。
- [ ] 所有动物角色都是完整动物头脸、人类比例双足直立身体、覆毛五指手和单条尾巴。
- [ ] 不出现普通四足宠物猫、纯人脸加猫耳、动物头套、玩偶服或兽装真人感。
- [ ] 狸同伟固定炭黑长外套；年轻狸同伟固定炭灰短夹克；喵亮平固定深蓝黑长外套。
- [ ] 喵亮平面罩斑、绿眼、胸白毛、白色五指手与足部固定，无徽章和武器。
- [ ] 每只手恰好五指，无肉色人手、少指、多指或融合手掌。
- [ ] 两名猫人儿童、三名犬人和五名社区猫人数量、花色与服装稳定。

## C. 画面与镜头

- [ ] 所有图片为 gpt-image-2 生成，1024×1024、1:1。

- [ ] 门窗、台阶、旧街、洪水与全部道具均为约 1.8m 拟人角色适用的人类尺度。
- [ ] 每个 Omni 任务总时长在 3–15 秒，内部镜头秒数与设置求和相等。
- [ ] 现在时在 VID-011 前无雨无风、枯叶不动；VID-011 风才第一次起来；VID-015 枯叶重新伏下。
- [ ] 没有直升机、车辆、现代设备、字幕、logo、水印或无关文字。
- [ ] 每个任务参考图不超过 7 张，Prompt ID 与上传 ID 完全一致。
