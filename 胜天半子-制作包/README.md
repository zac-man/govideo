# 《胜天半子》Seedance 2.0 制作包

本目录是《胜天半子》的 Seedance 2.0 可执行制作稿。原始故事以项目根目录的 `胜天半子.md` 为事实基准；旧版制作剧本仅作审校归档，不作为生成稿。

## 固定生成规格

- 图片：`GPT Image`，1:1，PNG；角色采用一张全身图加一张头肩图。
- 视频：`Seedance 2.0`，1:1，1080p（或平台可选最高档），原生普通话音画。
- 视频输入：按每个任务写明的上传顺序映射为 `@图片1`、`@图片2`……；不使用主体库别名。
- 时长策略：成片建议为 8、10 秒两档；不再统一生成 15 秒。镜头时长不写入提示词，由模型按镜头顺序自然分配。
- 台词：全部置于对应 Seedance 提示词的 `{}` 内，逐条生成；标题由后期叠加，避免模型错字。

## 镜头任务

10 个叙事段落已细分为28个独立生成片段。每段只承载一个主要动作或一条完整台词，建议总片长约198秒；需要压缩时优先删减无台词反应片段，绝不给角色加速说话。

| 目录 | 内容 |
|---|---|
| `01-全局规范` | 视觉、声音、素材映射与 Seedance 提交规范。 |
| `02-角色` | 角色与群演的不可变特征、表演边界。 |
| `03-场景` | 现在时与闪回场景的空间、光线、色彩定义。 |
| `04-道具` | 剧情锚点道具与模型自行生成细节的边界。 |
| `05-图片任务` | 角色、环境、道具参考图任务。 |
| `06-镜头任务` | 10 个可独立提交的 Seedance 2.0 提示词。 |
| `07-装配与验收` | 时间线、资产映射、批次顺序和验收规则。 |

## 推荐执行顺序

1. 生成并验收角色、木屋和 CS/LR4 参考图。
2. 按 `01-全局规范/03-Seedance请求规范.md` 的上传映射准备图片与两条干净的角色声音参考。
3. 按 `06-镜头任务` 顺序复制“Seedance 2.0 完整提示词”生成；每条独立上传相应素材。
4. 在剪辑中按时间线拼接，统一响度并在最后叠加标题；不改变对白播放速度。
5. 按验收清单复核，失败时只返工对应任务；仅当源图身份错误时才返工图片。
