# 《胜天半子》1:1 Omni 制作包

本目录是对《胜天半子》的可执行拆分。原始故事以项目根目录的 `胜天半子.md` 为事实基准，旧版 `胜天半子-制作剧本.md` 仅作为审校对象，不再作为直接生成稿。

## 作品形态

本片是**拟人化猫人漫剧**，不是普通宠物猫动画。所有主要猫角色统一采用：

- 猫科头部、口鼻、立耳、毛发、花纹、眼睛和一条尾巴。
- 人类成年/儿童比例的直立躯干、肩臂、双腿和自然服装。
- 覆毛的人类式五指手，可完成持物、指向、扶持和细腻表演。
- 面部仍是猫科结构，依靠耳朵、眼神、口鼻和胡须共同表演并完成普通话口型。

禁止生成普通四足宠物猫、纯人脸、动物头套、玩偶服、兽装表演者或“猫头直接贴在人身上”的拼接感。

## 固定生成规格

- 图片：`gpt-image-2`，`1024×1024`，1:1，PNG。
- 视频：Kling 3.0 Omni 参考图视频，1:1，1080p，原生音频。
- 视频输入：只用 `refer_image`，禁止 `first_frame`、`last_frame` 和参考视频。
- 单次视频任务总时长：3–15 秒；本包为 9–15 秒。
- 单个内部镜头：4–8 秒；每个任务最多 3 镜。
- 台词：全部写进对应 Omni 完整提示词，由模型原生生成，不做后期配音。
- 角色正式名：`狸同伟`；简称：`同伟`；形象：成年狸花猫人。

## 推荐执行顺序

1. 阅读 `00-审核与定稿/04-修订制作剧本.md`，确认剧情与台词。
2. 依次生成 `05-图片任务` 中的 6 张 1:1 参考图；只锁定主角、核心空间和反复出现的狙击步枪。
3. 按 `06-镜头任务` 的顺序提交 8 个 Omni 任务。一次性闪回场景、群演、粮袋、草药、空食盆、罐头和标题均在视频 Prompt 中直接生成，不另出参考图。
4. 按 `07-装配与验收/01-总时间线.md` 顺序拼接。原生台词不得另配音或替换。
5. 按验收清单逐项复核，失败时优先返工对应视频任务；只有人物、木屋或 CS/LR4 外观漂移才返工参考图。
